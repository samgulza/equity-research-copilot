# Risk Policy

This project is a research assistant, not an execution system.

## Prohibited

- Placing orders
- Connecting broker APIs for execution
- Managing private keys or exchange credentials
- Generating guaranteed-return language
- Hiding uncertainty or counter-evidence

## Required in every report

- Time horizon
- Confidence level
- Evidence and counter-evidence
- Invalidation conditions
- Source appendix
- Statement that output is research assistance, not financial advice

## Supply-chain controls

- Review all OpenClaw/ClawHub skills before installing.
- Pin dependencies in production.
- Use read-only API keys where possible.
- Do not feed confidential strategy/portfolio data to untrusted hosted models.
